# Linux Desktop Control Skill

This skill allows controlling desktop applications and performing system operations using Python scripts.

## Prerequisites

- **DISPLAY Environment Variable**: This variable is essential. If missing, ask the user to provide it.

## Workflow

### 0. Initialization
Run the setup script to prepare the workspace and verify the environment.

**Command:**
```bash
./setup.sh
```

### 1. Screenshot
Capture a screenshot using system tools like `xfce4-screenshooter` or `gnome-screenshot`.

**Storage Requirements:**
- Images must be stored in: `~/.openclaw/workspace/linux-desktop-control/images/`
- Filenames must be unique and include a timestamp.

**Example Command:**
```bash
xfce4-screenshooter -f -s ~/.openclaw/workspace/linux-desktop-control/images/desktop_screeshot_$(date +%Y%m%d_%H%M%S).png
```

### 2. UI Element Detection (Sub-agent)
Start a sub-agent to analyze the screenshot content.

**Prompt for Sub-agent:**

```
You are a **top-tier browser desktop UI element detection expert**, specializing in high-precision localization of interactive areas in computer screen screenshots (Chrome/Edge browser windows, system controls).

**Core Task**: Detect **ALL** visible UI elements (buttons, tabs, icons, text, controls, avatars, floating buttons, etc.) in the image with **extremely high recall**. **Do not miss a single one**. Even small 10-20 pixel close buttons, pure icons, or densely packed elements must be bounded.

**Strictly follow this scanning order** (from top to bottom, left to right covering every area):
1. Window Title Bar (Minimize, Maximize, Close buttons)
2. Browser Tab Bar (Entire area of each tab + Close button of each tab must be **detected separately**)
3. Navigation/Toolbar (Back, Forward, Refresh, Address Bar, Search Box, Bookmark Star, Extension Icons, Menu Button, etc.)
4. Bookmark Bar, Sidebar, Status Bar
5. Content Area and any other clickable areas (Links, Input Boxes, Avatars, Floating Controls, etc.)
6. If there is only an icon without text description, infer what it is based on the icon style as much as possible.

**Key Detection Categories** (Must cover [{target_object}] and all relevant interactive elements):
- All browser tabs + Close (×) button for each tab
- Window control buttons (3 buttons)
- All icons/buttons in the navigation bar
- Address bar, search box, bookmark bar, extension bar
- Any text labels, pure icon buttons, input boxes, menu items, scroll bars, etc.

**Bbox Precision Iron Rule** (Crucial for accurate positioning):
- Each bbox must **tightly enclose the visual boundary of the element** (tight bounding box), with at most 5% padding. Do not leave large empty spaces or crop content.
- Coordinates must be strictly normalized to 0~1000 integers: `x = round((pixel_x / image_width) * 1000)`, same for y.
- Ensure x1 < x2, y1 < y2, and all values are within the 0~1000 range.

**Text Naming Rules** (Must be globally unique):
- When text is present: Combine text + function (e.g., "Google Tab")
- For duplicate elements, force distinction (e.g., "Google Tab Close Button", "3rd Tab Close Button", "Window Title Bar Close Button", "Address Bar Refresh Button", "1st Extension Icon on the Left")

**Output Requirement**: **Return pure JSON only**, no explanations, thinking process, code blocks, markdown, or other text! Output directly now:

{{
  "objects": [
    {{"text": "Unique Description", "bbox": [x1, y1, x2, y2]}},
    ...
  ]
}}
```

### 3. Coordinate Conversion
The JSON file generated by the previous sub-agent needs to be saved to `~/.openclaw/workspace/linux-desktop-control/json/` with the name `{original_image_name}_original.json`.
These coordinates are normalized (0-1000). Convert them to absolute coordinates using `coordinate_conversion.py`.

**Note:** `coordinate_conversion.py` requires `NotoSansSC-VariableFont_wght.ttf` in the skill path.

**Command:**
```bash
python3 scripts/coordinate_conversion.py \
  --input=~/.openclaw/workspace/linux-desktop-control/json/{original_image_name}_original.json \
  --output=~/.openclaw/workspace/linux-desktop-control/json/{original_image_name}_converted.json \
  --tag_image=~/.openclaw/workspace/linux-desktop-control/json/{original_image_name}_export.json
```
- `--input`: Original JSON with normalized coordinates.
- `--output`: JSON with absolute coordinates.
- `--tag_image`: Path to save the tagged image for verification.

### 4. Mouse Control
Use `scripts/mouse_control.py` to control the mouse.

**Examples:**
```bash
# Click
python3 scripts/mouse_control.py click 300 400

# Double Click (custom duration)
python3 scripts/mouse_control.py double 500 300 --duration 0.4

# Drag
python3 scripts/mouse_control.py drag 100 100 400 400 --duration 1.2

# Right Click
python3 scripts/mouse_control.py right 600 500

# Scroll Down
python3 scripts/mouse_control.py scroll 200 200 -300
```

### 5. Keyboard Control
Use `scripts/keyboard_control.py` to control the keyboard.

**Examples:**
```bash
# Press Enter
python3 scripts/keyboard_control.py press enter

# Press Tab 3 times
python3 scripts/keyboard_control.py press tab --presses 3 --interval 0.15

# Ctrl + C
python3 scripts/keyboard_control.py hotkey ctrl c

# Ctrl + Shift + N (New Window)
python3 scripts/keyboard_control.py hotkey ctrl shift n

# Type Chinese text + emoji
python3 scripts/keyboard_control.py type "Hello World! 🌍✨" --interval 0.05 --enter

# Paste multiple lines of code (from file)
python3 scripts/keyboard_control.py lines --file script.py --line-interval 0.8 --char-interval 0.035

# Type multiple lines of text directly
python3 scripts/keyboard_control.py lines --text "First line\nSecond line with emoji 😺\nThird line end" --line-interval 1.0
```
